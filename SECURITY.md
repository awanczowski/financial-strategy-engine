# Security Policy

## Supported Versions

We release security patches and updates for the active release line of **Strategy Engine**:

| Version | Supported          |
| ------- | ------------------ |
| 1.8.x   | :white_check_mark: |
| < 1.7   | :x:                |

---

## Reporting a Vulnerability

The security of **Strategy Engine** is taken seriously. If you discover a security vulnerability or potential privacy issue (e.g. data leak in URL state encoding or client-side storage), please do **NOT** create a public GitHub issue.

Instead, please report vulnerabilities privately by emailing the maintainers or creating a private [GitHub Security Advisory](https://github.com/awanczowski/financial-strategy-engine/security/advisories/new).

### What to Include in Your Report

* Clear description of the vulnerability
* Steps to reproduce the security issue
* Potential impact of the vulnerability
* Any proposed mitigations or code fixes

### Response Timeline

* **Initial Acknowledgment:** Within 48 hours
* **Vulnerability Assessment & Triage:** Within 5 business days
* **Patch & Disclosure Target:** Within 30 days of confirmed triage

Thank you for helping keep **Strategy Engine** secure!
